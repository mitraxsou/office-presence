# Office Presence 2.0.4

Pilot Android build.

## What changed

- This day should not count now removes imported and previously corrected visits.
- A new correction replaces the existing corrected day instead of stacking visits.
- Failed correction requests show the reason on the phone.
- A correction that was not approved can be requested again.
- Immediately applied corrections show as applied instead of pending.
- Visits that cross midnight close at midnight and start a separately correctable new day.
- Fix today corrects today's times from Today, using a clock dial. Undo is available on a day you corrected yourself.
- You has switches for startup animation, startup sound, and Developer.
- Suggest an office is a form on You. An admin reviews it before it counts.
- Profile sits in the Share my status and Tracking card.
- Sound and vibration are changed with Change in Android settings.

## Install

1. Download the signed release APK (GitHub Release, /download, or Firebase App Tester).
2. On Android, allow installs from your browser (Install unknown apps).
3. Uninstall any debug build first if the signing key differs from this release.
4. Install, sign in with your PwC email, and allow location.
