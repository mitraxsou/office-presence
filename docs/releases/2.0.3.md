# Office Presence 2.0.3

Pilot Android build.

## What changed

- Quiet hours opens its own screen: start and end times, every day, weekdays, or custom days.
- Tracking problems and correction decisions can still alert during quiet hours.
- Notification rows put the value under the title so large text does not overlap.
- Sound and vibration changes open Android settings.
- Tapping your avatar opens Profile.
- Suggest an office opens Developer when developer mode is already on.

## Install

1. Download the signed release APK (GitHub Release, /download, or Firebase App Tester).
2. On Android, allow installs from your browser (Install unknown apps).
3. Uninstall any debug build first if the signing key differs from this release.
4. Install, sign in with your PwC email, and allow location.
