# Office Presence 2.0.2

Pilot Android build.

## What changed

- Year tab opens the month and day you tap, instead of always jumping to the current month.
- Quiet hours screen lets you set times, days, and which alerts still come through.
- Notification sound rows no longer overlap.
- App start sound includes built-in tones: Pulse, Chime, Soft, Spark, Ping, and Glide.
- Tapping your avatar opens Profile.
- Suggest an office opens Developer when developer mode is on.
- Large text wraps cleanly on settings and list rows.

## Install

1. Download the signed release APK (GitHub Release, `/download`, or Firebase App Tester).
2. On Android, allow installs from your browser (Install unknown apps).
3. Uninstall any debug build first if the signing key differs from this release.
4. Install, sign in with your PwC email, and allow location.
