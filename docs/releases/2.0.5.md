# Office Presence 2.0.5

Pilot Android build.

## What changed

- Admin review shows each corrected visit with its own office name.
- After an approval, Today refreshes so the approved day appears.
- Fix today starts empty when there is no visit yet (it no longer invents one).

## Install

1. Download the signed release APK (GitHub Release, /download, or Firebase App Tester).
2. On Android, allow installs from your browser (Install unknown apps).
3. Uninstall any debug build first if the signing key differs from this release.
4. Install, sign in with your PwC email, and allow location.
