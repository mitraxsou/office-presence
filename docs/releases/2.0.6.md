# Office Presence 2.0.6

Pilot Android build. Includes the 2.0.5 correction and Today fixes, plus the changes below.

## What changed

- A visit that is still open at midnight closes at local midnight and the new day starts right away. Each day can be corrected on its own.
- This day should not count removes that day's portion of a stored or imported visit, including a visit that crosses midnight.
- A short exit that returns inside the gap stays one visit.
- You has switches for startup animation, startup sound, and Developer. Developer can be turned off.
- Suggest an office is a name and address form. An admin reviews it before it counts.
- Profile sits in the Share my status and Tracking card.
- Rules shows correction approval, the monthly auto approve limit, and the no phone data setting.
- A day you corrected yourself is tagged Corrected by you.
- Quiet hours uses the clock dial.
- In, Out, goal, correction, and tracking notifications use the current wording and include this month's points.
- A coarse geofence exit no longer marks you Out.

## Install

1. Download the signed release APK (GitHub Release, /download, or Firebase App Tester).
2. On Android, allow installs from your browser (Install unknown apps).
3. Uninstall any debug build first if the signing key differs from this release.
4. Install, sign in with your PwC email, and allow location.
