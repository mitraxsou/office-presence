Launch animation

One continuous sequence from the system splash into the app, 1.5 seconds in total instead of about 2.2. The mark stays at the exact screen centre the whole time, where Android draws the splash icon, so the hand-off never jumps. Text appears below it, and the ripples stop before they reach the text. Tap anywhere to skip. With Startup animation off, or Android animations off, the app opens straight to Today.

Rules Once per app start, never on return from background. Launch sound starts with the dot at 200 ms. The greeting uses the cached preferred name and is left out on the very first launch. Sync and location checks start at 0 ms underneath, so the animation never delays data.
