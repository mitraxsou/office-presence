# PwC colors

| Token | Value | Role |
|---|---|---|
| `--pwc-orange` | `#FD5108` | Accent, primary buttons |
| `--pwc-orange-hover` | `#E04A07` | Primary hover |
| `--pwc-orange-muted` | `rgba(253, 81, 8, 0.15)` | Soft wash |
| `--background` | `#1A1A1A` dark / `#F4F4F4` light | Page |
| `--background-elevated` | `#2D2D2D` dark / `#FFFFFF` light | Cards |
| `--success` | `#2ECC71` | Met / positive only |

Do not invent purple, indigo, or teal AI accents. Brand chrome stays orange plus neutrals.
